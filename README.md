# guitar24t/homebrew-tap

Homebrew formulae for [rterm](https://github.com/guitar24t/rterm): persistent
terminal sessions that behave like a plain terminal.

```sh
brew install guitar24t/tap/rterm
```

This installs `rterm` (a universal binary for Apple Silicon and Intel Macs) and
`rterm-connect`, the session picker for connecting to hosts that run rterm.
`brew upgrade` picks up new releases.

`Formula/rterm.rb` is generated by rterm's release workflow from
[`packaging/homebrew/rterm.rb`](https://github.com/guitar24t/rterm/blob/main/packaging/homebrew/rterm.rb);
change the template there rather than editing it here.
